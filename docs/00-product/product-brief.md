# SWPanel 产品简介

## 1. 产品定位

SWPanel 是江海冶金内部使用的图纸自动建模与报价工作台。

产品目标不是替代机械工程师，而是利用 Agent 能力减少二维工程图转三维模型过程中的重复人工工作，并将自动建模结果进一步连接到企业内部报价流程。

核心定位：

> 从二维工程图到三维模型，再到内部报价报告的 AI 辅助工程工作台。

## 2. 用户范围

第一阶段仅服务江海冶金内部用户。

用户角色：

- 企业管理者
- 实际参与生产和技术审核的工程人员

用户具备：

- 熟练或精通 SolidWorks 操作能力
- 能够进行最终工程审核

## 3. 核心问题

机械加工领域存在大量二维工程图转三维模型的重复建模工作。

该过程：

- 消耗工程师时间
- 重复劳动比例高
- 影响报价效率

SWPanel 希望通过 Agent 自动化完成标准化建模工作，并保留人工审核环节。

## 4. MVP 核心闭环

第一版产品完成以下流程：

```
上传工程图
    ↓
图纸库长期保存
    ↓
用户主动发起自动建模
    ↓
Agent 调用 SolidWorks 建模能力
    ↓
生成模型与建模报告
    ↓
人工审核模型
    ↓
根据模型参数生成报价报告
    ↓
报价审核与归档
```

## 5. 产品原则

### 5.1 图纸是长期业务对象

上传图纸不会自动开始建模。

用户先管理图纸，再决定是否创建建模任务。

### 5.2 建模任务独立存在

一次图纸可以拥有多次 Agent 执行记录。

历史执行不可覆盖。

### 5.3 Agent 不允许工程猜测

当图纸信息不足、存在歧义或无法确定工程参数时，Agent 必须请求人工补充信息。

### 5.4 人工审核是必要环节

Agent 输出不直接视为生产可用模型。

只有人工审核通过后，模型才能进入报价流程。

### 5.5 本地优先

第一阶段部署于企业本地 Windows 环境。

不设计云端 SaaS、多租户等能力。
